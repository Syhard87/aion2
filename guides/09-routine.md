# 9. ✅ Routine quotidienne & hebdomadaire (niveau 45)

> **Réinitialisation quotidienne : ≈ 07:00 UTC** (9h heure de Paris jusqu'au 25 octobre, puis 8h en hiver). **Réinitialisation hebdomadaire : le mercredi.** ⚠️ Fie-toi au compte à rebours en jeu.
> Une checklist interactive avec réinitialisation automatique existe en ligne : *aion2builds.org/tools/checklist*.

## ☀️ Chaque jour (environ 30 à 60 min)

Copie-colle cette liste dans tes notes et coche-la :

```
[ ] 5 missions de devoir (Duty Missions)
[ ] Énergie Odyle : dépensée sous le plafond (560, ou 840 avec abonnement)
      → priorité : Conquête / Transcendance (40), raid
[ ] Nightmare : dépenser les essais (2 par jour, ne pas rester à 14)
[ ] Clés Shugo Festival : les utiliser (le Festival a lieu toutes les heures, clés partagées sur le serveur)
[ ] Dimensional Invasion (à :30 chaque heure) : utiliser la clé
[ ] Compteurs de Conquête / Transcendance : ne pas les laisser plafonner
[ ] Récolte sur le chemin + mise en vente des surplus sur le Marché
[ ] Événement en cours (Halloween jusqu'au 3 novembre)
```

## 📆 Chaque semaine (avant le mercredi)

```
[ ] Ascension Trial : 3 entrées (LES FAIRE EN DERNIER, à ton item level max)
[ ] Donjon quotidien : épuiser le compteur hebdomadaire (7 à 14 selon les sources)
[ ] Champ de bataille : 3 victoires
[ ] Arène : participation
[ ] Raid : utiliser les essais (4 par raid ⚠️)
[ ] Abysse : utiliser ses heures (les heures non utilisées sont PERDUES), boss de l'Abysse
[ ] Expédition : Conquête
[ ] Tickets de Subjugation et nombre d'explorations
[ ] Wind Breeze Merchant (abonnement) : pierres d'énergie Odyle, Soul Crystal, tickets de clear instantané
[ ] Achats limités par semaine dans les boutiques (parchemins Command / Abysse, artisanat d'Odyle)
[ ] Substance Morph : utiliser les conversions de la semaine (20 par serveur ⚠️)
```

## 🗓️ Chaque mois

```
[ ] Boutique du Shugo Festival : 15 cristaux Daevanion (50 Centuryroot Tokens chacun)
[ ] Achats limités par mois dans les autres boutiques
```

## ⏱️ L'ordre optimal d'une session

1. **Connexion** → lancer les choses qui sont **sur un timer** (Shugo Festival, Dimensional Invasion à :30).
2. **Missions de devoir** pendant les temps morts.
3. **Donjons à cubes** (énergie Odyle) en groupe, de préférence avec ta Légion.
4. **Nightmare** (solo, à faire quand ça t'arrange).
5. **Marché** : mettre en vente, racheter ce qui manque.
6. **En fin de semaine :** Ascension Trial ×3, puis les boss de l'Abysse.

## 👥 Rerolls (alts)

- Chaque perso a **sa propre énergie Odyle**. Un reroll au 45 = un deuxième revenu d'Odyle, de Kina et de matériaux.
- ⚠️ Les clés Shugo et certaines limites de boutique sont **par serveur**, pas par perso. Un reroll ne double donc **pas** tout.
- Avant d'en faire un, concentre-toi d'abord sur **un seul personnage principal** jusqu'à environ 2 000 d'item level.

### 📦 Passer des objets d'un perso à un autre

Le jeu n'a pas d'entrepôt de compte : on passe par l'**entrepôt de serveur** (*Server Storage*), qui ne fonctionne **qu'entre persos du même serveur**.
1. Va voir un PNJ **Storage Manager** (avec l'abonnement : bouton de **stockage à distance** en bas de l'inventaire).
2. Passe de l'onglet *Character Storage* à **Server Storage**, et dépose les objets **depuis ton inventaire** (pas depuis l'entrepôt du perso).
3. Connecte-toi sur ton autre perso et récupère-les au même endroit.

| ✅ Transférable | ❌ Non transférable |
|----------------|---------------------|
| **Kina non liés** | Kina liés |
| Consommables (nourriture, potions), minerais et matériaux | Récompenses de quête |
| Équipement **pas encore lié** (jamais équipé) | Équipement **lié à l'âme** (*Soul Bound*), donc déjà équipé |
| | Objets marqués **« Bound »** dans l'infobulle |

- Pour un **autre serveur**, il faut passer par le **transfert de serveur** du perso (boutique, fenêtre ouverte jusqu'au 28 octobre ⚠️).
- Le **transfert d'équipement** (*Gear Transfer*, niveau 45) est autre chose : il déplace l'enchantement d'un objet vers un autre **du même perso**, pas entre persos.
- 💡 Si tu prévois un reroll, **n'équipe pas** les objets que tu veux lui passer.
